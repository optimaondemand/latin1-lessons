★ How to Give an Order
Lesson · about 42 minutes
📖 TODAY'S FOCUS
One order, two sizes: to one person, and to a group. Plus four short verbs that break the rule.
The imperative is one of the friendliest forms in Latin, because you already have everything you need to build it. Command one person? Take the verb's present stem. Command a group? Add -te. That's the whole rule — and it works across the first, second, and third conjugations you've been studying all semester. At the end you'll meet four everyday verbs with a clipped singular: dīc, dūc, fac, fer.
🎯 BY THE END OF THIS LESSON YOU WILL BE ABLE TO…
1
I will be able to form the singular imperative (to one person) from a verb's present stem.
2
I will be able to form the plural imperative (to a group) by adding -te.
3
I will be able to recall the four irregular short singulars: dīc, dūc, fac, fer.

📚 PART 2 · COMMANDING ONE PERSON 10 min

The singular: just take the stem

To order one person, take the verb's present stem — the infinitive with its -re dropped. For the first and second conjugations, that's all there is to it. The third conjugation keeps a short -e.

ConjugationInfinitiveSingular commandMeaning
1stamāreamālove!
1stportāreportācarry!
2ndmonēremonēwarn!
2ndvidērevidēsee! / look!
3rdmitteremittesend!
3rdscrīberescrībewrite!
💡 NOTICE THE VOWEL

The singular command wears the family's signature vowel: long ā for the first conjugation (amā), long ē for the second (monē), and a short e for the third (mitte). Same idea you learned with the present tense — the stem vowel tells you the family.

📌 PART 3 · COMMANDING A GROUP + FOUR REBELS 12 min

The plural: add -te

To order a group, add -te to the singular. (In the third conjugation the short e becomes an i before the ending: mitte → mittite.)

ConjugationSingular (one person)Plural (a group)
1st — amāreamāamāte
1st — portāreportāportāte
2nd — monēremonēmonēte
3rd — mitteremittemittite

Four common third-conjugation verbs clip their singular command down to nothing but the bare stem — no final vowel at all. Their plurals, though, are perfectly regular.

⚠️ THE FOUR IRREGULAR SINGULARS — MEMORIZE THESE
VerbSingularPluralMeaning
dīceredīcdīcitesay! / speak!
dūceredūcdūcitelead!
facerefacfacitedo! / make!
ferreferfertecarry! / bring!

A tidy memory hook: “dīc, dūc, fac, and fer — should have an -e, but it isn't there.”

✅ PART 4 · BUILD THE COMMAND 16 min

Five reps — forming singulars, forming plurals, and catching the four rebels. Keep the charts above in view; the goal is to make the command form automatic.

✅ TRY IT · command one person
Order one person to warn, using monēre. Which form?
✅ TRY IT · command a group
Order a group to carry, using portāre. Which form?
✅ TRY IT · third conjugation
Give the singular command of mittere (“send!”).
✅ TRY IT · catch the rebel
Which is the correct singular command “lead!” from dūcere?
✅ TRY IT · command a group
Tell a group to speak, using dīcere. Which form?

Produce both forms yourself: give the singular and the plural command for “carry!” (portāre). Say them, then reveal.

portā (to one person) and portāte (to a group). Stem portā- for the singular; add -te for the plural. Same move for every first-conjugation verb.
